# 메인 화면 · 게임 흐름

접속하면 전장이 내려다보이는 자리에서 메인 화면이 뜹니다. 거기서 튜토리얼 · 훈련장 · 경기로 들어갑니다.

```
접속 → 메인 화면 ┬─ 플레이 ─┬ (처음) 튜토리얼
                │          └ 규격 선택 ┬ 1대1 매치 → 대기 → 경기
                │                      ├ 팀 격전 ┬ 2대2 → 대기(4명) → 편 짜기 → 경기
                │                      │         └ 3대3 → 대기(6명) → 편 짜기 → 경기
                │                      └ 대난투   → 모집 → 경기 (중도 난입 · 꽉 차면 관전)
                ├─ 훈련장 ── 규격 선택 → 훈련장 방
                ├─ 패치노트
                ├─ 설정 (바닐라 설정 창)
                ├─ 관리자 모드 (게임마스터만)
                └─ 나가기
게임 중 → ESC 메뉴 "메인 화면으로" → (확인) → 메인 화면
```

"규격" 은 직업입니다 — 게임 종류를 고르기 전에 먼저 고릅니다.

## 서버 (`kr.overbreak.game`)

| 파일 | 하는 일 |
|---|---|
| `Game` | 접속 · 흐름 전환 · 대기열 · 입력/피해 막기. `enabled` 가 false 면 접속해도 메인 화면으로 보내지 않음 (시험 실행) |
| `Session` | 플레이어가 지금 어디에 있는가 (MENU · QUEUE · TUTORIAL · TRAINING · DUEL · BRAWL · TEAM · FREE) + 튜토리얼 완료 여부 (월드에 저장) |
| `Places` | 로비 · 메인 화면 시점 · 훈련장 · 전장 · 팀전 · 대난투 시작 자리 · 튜토리얼 좌표 |
| `Tutorial` · `Training` · `Duel` · `TeamMatch` · `Brawl` | 각 모드 |
| `ScoreBoard` | 점수판(`net/ScorePayload`)을 바뀐 때만 보냄 |

- 메인 화면에서는 관전 모드로 `MENU_VIEW` 에 세워 두고, 입력(스킬 · 평타)과 피해를 막습니다.
- 모드가 없는 클라이언트는 로비에 서서 채팅 버튼 · `/lobby …` 명령으로 같은 것을 합니다.
- 관리용: `/ob tutorial skip`, `/ob tutorial reset`, `/ob free` (관리자 모드).
- 모드 없는 클라이언트: `/lobby duel|team|team2|brawl|training <직업>`.

### 전투 감각 (0.1c)

- **넉백 없는 피해는 맞은 사람의 움직임을 건드리지 않습니다** (`SkillDamage.raw` · `MeleeCleave`).
  바닐라는 맞을 때마다 `hurtMarked` 로 속도 패킷을 보내 클라이언트 속도를 덮어쓰는데, 연사에 맞으면
  그때마다 미끄러지듯 느려집니다. 맞기 직전 속도로 되돌리고 속도 패킷도 보내지 않습니다.
- **피격 피드백**: 바닐라 화면 기울기(`bobHurt`)를 끄고 (`GameRendererBobMixin`),
  맞은 방향에 붉은 호를 띄웁니다 (`net/HurtPayload` → `client/hud/DamageFeedback`).
  같은 방향에서 연달아 맞으면 호가 하나로 뭉쳐 진해질 뿐이라 조준이 흔들리지 않습니다.
- **경기 투입 연출**: 전장에 들어갈 때 튜토리얼 오프닝과 같은 부팅 화면이 2초 돕니다
  (`game/Opening` → `TutorialCuePayload.BOOT` + `"match"`). 시점은 건드리지 않고 문구만 전장용입니다.

### 1대1 매치 (`Duel`)

두 명이 모이면 전장 양 끝에서 3선승제. 점수는 액션바가 아니라 **화면 위쪽 점수판**(오버워치 방식)에 뜹니다 — 양쪽 큰 숫자 + 딴 점수만큼 채워지는 칸, 아래에 라운드.

### 팀 격전 (`TeamMatch`)

**2대2 · 3대3** 중에 고릅니다. 인원이 대기열에 모이면 먼저 **편 짜기 화면**이 떠서
플레이어가 직접 청팀 · 홍팀을 고릅니다 (`TeamDraftScreen` ↔ `net/TeamDraftPayload`).
15초 안에 고르지 않으면 빈자리에 자동으로 들어가고, 양쪽이 다 차면 바로 시작합니다.
한 팀을 **전멸**시키면 상대 팀이 1점, 먼저 **3점**을 내면 승리 (제거전).

- 쓰러지면 죽지 않고 그 라운드 동안 관전, 다음 라운드에 모두 다시 일어납니다.
- **아군은 판정에서 통째로 빠집니다** — `Targets.allies` 갈고리를 `Game.sameTeam` 이 채우고,
  `Targets.enemies` · `Hitscan` · `MeleeCleave` · `BloodChain` 이 모두 이 갈고리를 봅니다.
  그래서 아군에게는 피해 · 군중 제어가 들어가지 않고 총알도 막히지 않고 지나갑니다.
- **테두리**는 보는 사람마다 다릅니다 (`net/TeamPayload` → `client/hud/MatchTeams`):
  우리 편은 **파랑**(벽 너머로도), 상대는 **빨강**(눈에 보일 때만 — 벽 뒤는 비치지 않게 몇 틱마다 시야를 봅니다).
  스코어보드 팀 색은 모두에게 같은 색이라 쓰지 않고, `MinecraftGlowMixin` 으로 테두리를 켜고
  `EntityRendererMixin` 이 `EntityRenderState.outlineColor` 를 칠합니다.
- 점수판은 `[ 우리 팀 ] 파랑 : 빨강 [ 상대 팀 ]` + 라운드 · 생존 수.

### 대난투 (`Brawl`)

한 전장에 **최대 5명**, 목표 킬은 **사람 한 명당 10킬** (3명 30킬 · 4명 40킬 · 5명 50킬).

- **3명**이 모이면 10초 카운트다운이 돌고, 그 사이에 들어온 사람도 5명까지 함께 들어갑니다.
- **중도 난입**: 경기 중에 골라도 자리가 남아 있으면 바로 들어갑니다 (목표 킬이 10 올라갑니다). 꽉 차 있으면 관전.
- 쓰러지면 죽지 않고 3초 뒤 **다른 사람에게서 가장 먼** 시작 자리에서 다시 일어납니다. 쓰러뜨린 사람이 1킬.
- 쓰러져 있는 동안 **규격 선택 창**이 떠서 다음 판에 쓸 규격을 바꿀 수 있습니다 (`MenuPayload.RESPAWN`).
- 점수판에는 순위표(이름 · 킬)가 뜨고 내 줄이 밝게 표시됩니다.
- 전장 밖으로 나가면 시작 자리로 되돌립니다.

### 관리자 모드 (`Game.toFree`)

게임마스터 권한이 있으면 메인 화면에 「관리자 모드」 가 보입니다 (`/ob free` 도 같음).
크리에이티브로 바뀌고 전장 · 훈련장의 제한(자리 되돌리기 · 입력 · 피해 막기)이 모두 풀려 맵을 자유롭게 돌아다닙니다.
ESC 메뉴의 「메인 화면으로」 또는 `/lobby` 로 돌아옵니다.

## 클라이언트 (`kr.overbreak.client.lobby`)

서버가 `MenuPayload`(CLOSED · MAIN · QUEUE)를 보내면 그대로 창을 띄웁니다. 누르면 `MenuActionPayload` 로 돌아갑니다 (서버가 조건을 다시 확인).

| 파일 | 화면 |
|---|---|
| `LobbyClient` | 상태 받기 · 창 열고 닫기 · ESC 메뉴에 "메인 화면으로" 버튼 · 메인 화면 동안 1인칭 고정 |
| `LobbyScreen` | 메인 화면 (플레이 · 훈련장 · 패치노트 · 설정 · 나가기) |
| `PatchNotesScreen` · `PatchNotes` | 패치노트 — 버전 · 직업별 변경점, 꼬리표 (버프) 파랑 · (너프) 빨강 · (조정) 회색. 새 버전은 `PatchNotes.VERSIONS` 맨 앞에 추가 |
| `ClassSelectScreen` | 규격 선택 (오버워치 방식) — 아래 초상화 카드 한 줄 + 위에 큰 초상화 · 소개 · 능력치 · 스킬. 고를 때마다 픽 연출 (초상화가 밀려 들어오며 섬광 · 빛줄기, 카드가 튀어오르고 스킬이 차례로 들어옴) |
| `ModeSelectScreen` | 게임 종류 (1대1 매치 · 팀 격전 · 대난투) — 카드 세 장 |
| `TeamSizeScreen` | 팀 격전 인원 (2대2 · 3대3) |
| `TeamDraftScreen` | 편 짜기 — 청팀 · 홍팀 칸을 눌러 직접 고름 |
| `QueueScreen` | 매칭 대기 (지난 시간 · 취소) |
| `LobbyBase` | 공통 — 기울어진 버튼 · 클릭 자리 · 큰 글자 |
| `hud/ScoreHud` | 경기 점수판 (화면 위쪽 가운데) — 1대1 · 3대3은 큰 숫자, 대난투는 순위표 |
| `hud/MatchTeams` | 팀전 테두리 색 (우리 편 파랑 · 상대 빨강, 보는 사람마다 다름) |
| `hud/DamageFeedback` | 피격 피드백 (맞은 방향의 붉은 호 · 가장자리) — 바닐라 화면 기울기는 끕니다 |

규격 초상화는 `assets/overbreak/textures/gui/sprites/portrait/<직업 id>.png` (144x176) — 그림만 갈아 끼우면 됩니다.

- 화면은 전장이 비치도록 한쪽만 덮습니다. 게임은 멈추지 않습니다 (`isPauseScreen` false).
- ESC 는 뒤로 가기이며 메인 화면은 닫히지 않습니다. 창이 사라지면 다음 틱에 다시 띄웁니다.

## 튜토리얼

「코어」가 화면 **위쪽 대사창**으로 말합니다 (초상화 + 글자가 한 자씩 찍힘). 채팅으로는 더 이상 말하지 않습니다 — 모드가 없는 클라이언트만 채팅으로 대신 받습니다.

시작하면 **가상세계가 켜지는 연출**이 먼저 돕니다: 새까만 화면에서 가로 틈이 열리듯 위아래 검은 띠가 물러나고, 그동안 시야각도 좁은 데서 제자리로 넓어집니다. 격자 · 주사선 · 지직거림 · 부팅 문구가 지나간 뒤 흰 섬광과 함께 「OVERBREAK」.

단계 (`game/Tutorial.java`)

| 단계 | 내용 | 넘어가는 조건 |
|---|---|---|
| 0 부팅 | 켜지는 연출 · 첫 대사 (발이 묶임) | 대사 끝 |
| 1 이동 | W A S D | 움직인 총 거리 6칸 (시작 칸이 장벽으로 막혀 있어 직선 거리가 아님) |
| 2 도약 | 스페이스 | 3회 |
| 3 웅크리기 | 웅크리기 | 1초 유지 |
| 4 장벽 | 에너지 장벽이 꺼지고 통과 | 장벽 너머로 |
| 5 규격 수신 | 워리어 지급 · 체력 275 · 공격력 36 · 공격속도 · 스킬 쿨 설명 (체력 막대 화살표) | 대사 끝 |
| 6 평타 | 좌클릭 (무기 칸 화살표) | 표적 5회 |
| 7 출혈 | 패시브 설명 | 대사 끝 |
| 8~11 | 살육 · 광란의 포효 · 피의 사슬 · 광란의 처형장 (각 스킬 칸 화살표) | 각 스킬 사용 · 적중 |
| 12 규격 정보 | F8 안내 | F8 화면을 열면 (클라이언트가 알려 줌) |
| 13 마무리 | 완료 기록 → 메인 화면 | 대사 끝 |

- **에너지 장벽** (`game/EnergyBarrier.java`): 시작 칸을 막는 벽. 실제로 막는 것은 보이지 않는 barrier 블록 한 겹(x 107 · z -22~-9 · 높이 12칸)이고, 눈에 보이는 것은 푸른 빔 격자(세로 1칸마다 · 가로 2칸마다) + 위아래 흰 레일 + 위아래로 훑는 띠 + 푸른 불꽃과 낮은 웅웅거림입니다. 열릴 때는 전원이 꺼지듯 접히며 사라집니다.
- **화살표**: 지금 써야 할 HUD 칸(스킬 · 궁극기 · 무기 · 체력) 위에서 통통 튀고, 스킬 칸은 둘레가 숨 쉬듯 밝아집니다.
- 스킬은 각 단계 전에는 잠겨 있습니다 (누르면 "아직 해제되지 않은 규격이다").
- 죽으면 그 단계 자리에서 다시 시작하고 화살표도 되살아납니다.

| 파일 | 하는 일 |
|---|---|
| `net/DialoguePayload` · `TutorialCuePayload` · `TutorialAckPayload` | 대사 한 줄 · 연출 지시(부팅 · 화살표 · 지직) · 클라이언트 보고(F8) |
| `client/tutorial/CoreDialogue` | 대사창 (초상화 · 타자 · 신호음 · ▼) |
| `client/tutorial/BootSequence` | 켜지는 연출 (검은 띠 · 시야각 · 격자 · 부팅 문구) |
| `client/tutorial/HudPointer` | HUD 화살표 |

코어 초상화는 `assets/overbreak/textures/gui/sprites/tutorial/core.png` — 그림을 바꾸고 싶으면 이 파일만 갈아 끼우면 됩니다 (128x128).

## 시험

`LobbyClientTest` 가 실제 마우스 클릭으로 흐름을 따라갑니다 (메인 → 튜토리얼 → ESC 메뉴 버튼 → 훈련장 → 규격 → 입장 → 플레이 → 규격 → 게임 종류 → 대기 → 취소 → 대난투 모집 → 점수판 → 관리자 모드). 화면은 `build/run/clientGameTest/screenshots` 에 남습니다.

```bash
OVERBREAK_CLIENT_TEST=LobbyClientTest ./gradlew runClientGameTest
```

`TeamOutlineClientTest` 는 앞에 마네킹을 세우고 우리 편 → 상대 편으로 바꿔 가며 테두리 색을 찍습니다.

```bash
OVERBREAK_CLIENT_TEST=TeamOutlineClientTest ./gradlew runClientGameTest
```

`TutorialClientTest` 는 부팅 연출 · 대사창(글자가 늘어나는지) · 화살표를 찍고, 실제 키 입력으로 이동 → 도약 → 웅크리기 → 장벽 → 규격 수신까지 지나갑니다.

```bash
OVERBREAK_CLIENT_TEST=TutorialClientTest ./gradlew runClientGameTest
```

시험 실행은 `-Doverbreak.lobby=false` 로 메인 화면을 꺼 두고 (직업 시험이 메뉴에 갇히지 않게), 이 시험만 스스로 켜고 `Game.join` 을 부릅니다.
